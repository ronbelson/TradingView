# 07 Zap — story

## Role for the meter
Live tape color + touch magnets.
Answers: is the candle tape green/red/purple/gray, and where are the most-touched upper (resistance) and lower (support) levels.

## Core
- Slow MA pair 50/200 (or Fast 9/21) + MACD condition → green/red tape
- RSI >70 → purple (stretched up)
- RSI <30 → gray (stretched down)
- Optional 3-MA slope align (50/200/200-style trio)

## Upper / lower points (Timeframe Lines)
Clusters highs and lows over lookback, counts touches, draws:
- Red levels = top touched highs (upper / resistance dots-lines)
- Green levels = top touched lows (lower / support dots-lines)
Default now: **use chart timeframe** (not locked to 240).

## Meter vote (for Stack Meter)
- Green tape → up lean
- Red tape → down lean
- Purple → late / do-not-chase up
- Gray → late / bounce watch
- Near upper touch level → resistance pressure
- Near lower touch level → support bounce
